Here is a comprehensive, production-grade architectural plan and implementation roadmap for building **Cobass** (`com.maxica.cobass`), a Cubase-inspired modular Android DAW using C++ and AAudio, built entirely via standalone CLI toolchains without Android Studio or Gradle.

---

# 1. System Architecture Design

```
+-----------------------------------------------------------------------------------+
|                              UI LAYER (Native / JNI)                              |
|  [Arranger View]  |  [Piano Roll]  |  [Wave Editor]  |  [Mixer & Plugin Rack]     |
+------------------------------------------+----------------------------------------+
                                           | Lock-Free SPSC Queues (No Mutexes)
                                           v
+-----------------------------------------------------------------------------------+
|                        DAW CORE ENGINE (C++20 Architecture)                       |
|                                                                                   |
|  +---------------------+  +----------------------+  +--------------------------+  |
|  |   Project Model     |  |   Transport & Tempo  |  | Modular Plugin System    |  |
|  | - Tracks & Clips    |  | - Sample/Tick Clock  |  | - Custom VST-like Node   |  |
|  | - Automation Nodes  |  | - Quantize Engine    |  | - Dynamic DSP Pipeline   |  |
|  +---------------------+  +----------------------+  +--------------------------+  |
|                                                                                   |
|  +-----------------------------------------------------------------------------+  |
|  |                              MIXER GRAPH                                    |  |
|  |   [Synth/Audio Track 1]  [Synth/Audio Track 2]  ...  [FX Send / Aux Buses]  |  |
|  |             \                     /                         /               |  |
|  |              +-------------------+-------------------------+                |  |
|  |                                  v                                          |  |
|  |                             [Master Bus]                                    |  |
|  +----------------------------------+------------------------------------------+  |
+-------------------------------------+---------------------------------------------+
                                      | Direct Buffer Fill
                                      v
+-----------------------------------------------------------------------------------+
|                  LOW-LATENCY DRIVER (AAudio / Real-Time Thread)                   |
|   AAudioStream_dataCallback() -> Exclusive Performance Mode -> Hardware Output    |
+-----------------------------------------------------------------------------------+
```

### Real-Time Audio Constraints
1. **Audio Callback Safety**: The AAudio real-time thread must **never**:
   - Allocate/free memory (`malloc`, `new`, `free`, `delete`).
   - Acquire blocking primitives (`std::mutex`, semaphores).
   - Perform I/O or JNI calls.
2. **Lock-Free Communication**: Use Single-Producer Single-Consumer (SPSC) lock-free ring buffers for UI-to-Engine messages (parameter tweaks, note triggers, clip edits) and Engine-to-UI telemetry (VU meters, playhead position).

### Phase 1: Barebones Engine & Standalone CLI Pipeline

* **Goal**: Build and deploy an APK (`com.maxica.cobass`) for Android 14 (API 34) producing a clean sine tone via AAudio using only command-line tools.
* **Tasks**:
  1. Set up standalone toolchain using Android SDK (`aapt2`, `d8`, `zipalign`, `apksigner`) and NDK `clang++`.
  2. Implement `AAudioEngine` in C++:
     - `AAudioStreamBuilder_setPerformanceMode(builder, AAUDIO_PERFORMANCE_MODE_LOW_LATENCY);`
     - `AAudioStreamBuilder_setSharingMode(builder, AAUDIO_SHARING_MODE_EXCLUSIVE);`
     - `AAudioStreamBuilder_setFormat(builder, AAUDIO_FORMAT_PCM_FLOAT);`
  3. Create standard lock-free ring buffer for UI-to-Audio-thread communication.

---

### Phase 2: Modular DSP & Mixer Graph Architecture

* **Goal**: Enable dynamic track addition, synths, and audio samplers.
* **Modular Node System**:
  ```cpp
  class AudioNode {
  public:
      virtual ~AudioNode() = default;
      virtual void process(const float* inBuffer, float* outBuffer, int numFrames) = 0;
      virtual void setParameter(uint32_t paramId, float value) = 0;
  };
  ```
* **Track Types**:
  - **Synth Track**: Polyphonic additive/subtractive synth with ADSR envelopes, resonant filter (low-pass, high-pass), and LFOs.
  - **Audio Track**: Multi-channel sample streaming with pitch/tempo scaling and gain envelopes.
* **Bus Architecture**:
  - Independent Tracks $\to$ Send Channels $\to$ Sub-mix Buses $\to$ Master Output.

---

### Phase 3: Arranger / Master Clip Editor (Cubase Workflow)

* **Goal**: Master timeline where clips are created, resized, moved, and rendered.
* **Workflow Implementation**:
  1. **Track Creation**: User taps `+ Track`, selects **Synth** or **Audio**.
  2. **Clip Drawing**:
     - Switch to **Pencil Tool**: Tap and drag over a track lane to create an empty clip aligned with the grid.
     - Switch to **Select Tool**: Drag clips across time/tracks, drag boundaries to trim or loop.
  3. **Arranger Capabilities**:
     - Quantized snap engine (1/4, 1/8, 1/16, 1/32, Triplet, Free).
     - Split/Razor tool: Cut a clip into two independent instances.
     - Duplicate, Mute, and Slip-edit modes.
     - Multi-touch pinch-to-zoom (horizontal time zoom, vertical track-height zoom).

---

### Phase 4: Dedicated Clip Editors (Double-Tap Activation)

* **Goal**: Double-tapping a clip opens the context-specific editor.

#### 1. MIDI Piano Roll (Synth Clips)
* **Canvas Grid**: Touch-responsive note grid with pitch ($0\text{–}127$) on the Y-axis and musical beats/ticks on the X-axis.
* **Note Interaction**:
  - **Draw**: Single tap to place note (default length determined by grid snap).
  - **Resize**: Drag note tail to adjust length.
  - **Velocity Lane**: Lower drawer displays vertical bars for note velocities ($0\text{–}127$).
* **Cubase-Inspired Features**:
  - Scale Highlighting (Major, Minor, Pentatonic, Dorian).
  - Quantize Selection button.
  - Legato, Transpose ($\pm 12$ semitones), and Velocity Humanize.

#### 2. Waveform Audio Editor (Audio Clips)
* **Sample Display**: Mipmapped peak cache for rendering waveforms smoothly at any zoom level without lag.
* **Editing Toolkit**:
  - Non-destructive slicing, cropping, trimming.
  - Fade-in / Fade-out curve handles directly on the waveform.
  - Normalize peak ($0\text{ dB}$, $-1\text{ dB}$, $-3\text{ dB}$).
  - Reverse audio buffer.
  - Loop regions with crossfade support.

---

### Phase 5: Mixer Console & Modular FX Suite

* **Mixer Strip Components**:
  - Gain fader with logarithmic volume response ($-\infty$ to $+6\text{ dB}$).
  - Pan control (Constant-power panning law).
  - Solo, Mute, Record Arm, Phase Inversion.
  - Real-time VU / Peak metering via lock-free atomic peak extractors.
* **FX Insert Chain (Per-track & Master)**:
  - **Parametric 4-Band EQ**: High-pass, Low Shelf, Peaking, High Shelf with visual curve rendering.
  - **Dynamic Compressor**: Threshold, Ratio, Attack, Release, Knee, and Makeup Gain.
  - **Stereo Delay**: Tempo-synced time subdivisions, ping-pong mode, high-damp feedback.
  - **Convolution / Algorithmic Reverb**: Schroeder/Freeverb modular implementation.
  - **Master Brickwall Limiter**: Lookahead peak limiter with soft-clipping.

---

### Phase 6: Project Persistence, Offline Export & Low-Latency Polish

* **Project Serialization**: Save/load projects into a single file bundle (`.cobass` container containing JSON metadata and raw audio assets).
* **High-Speed Offline Rendering**:
  - Detach playback from real-time clock.
  - Process mixer graph at full CPU speed into a 24-bit/32-bit float Master `.wav` file.
* **Android Performance Optimization**:
  - Bind audio thread to big CPU cores using `pthread_setaffinity_np`.
  - Use NEON SIMD vectorization for all DSP vector math (mixing, filters, gain applications).

# 4. Core C++ Engine Blueprint

### Audio Engine (`AudioEngine.hpp`)
```cpp
#pragma once
#include <aaudio/AAudio.h>
#include <vector>
#include <memory>
#include "Track.hpp"
#include "LockFreeQueue.hpp"

enum class CommandType { AddTrack, RemoveTrack, NoteOn, NoteOff, ParameterChange };

struct EngineCommand {
    CommandType type;
    int32_t trackId;
    int32_t data1;
    float data2;
};

class AudioEngine {
public:
    AudioEngine() = default;
    ~AudioEngine() { stop(); }

    bool start() {
        AAudioStreamBuilder* builder = nullptr;
        if (AAudio_createStreamBuilder(&builder) != AAUDIO_OK) return false;

        AAudioStreamBuilder_setFormat(builder, AAUDIO_FORMAT_PCM_FLOAT);
        AAudioStreamBuilder_setChannelCount(builder, 2);
        AAudioStreamBuilder_setPerformanceMode(builder, AAUDIO_PERFORMANCE_MODE_LOW_LATENCY);
        AAudioStreamBuilder_setSharingMode(builder, AAUDIO_SHARING_MODE_EXCLUSIVE);
        AAudioStreamBuilder_setDataCallback(builder, dataCallback, this);

        aaudio_result_t res = AAudioStreamBuilder_openStream(builder, &stream_);
        AAudioStreamBuilder_delete(builder);
        if (res != AAUDIO_OK) return false;

        return AAudioStream_requestStart(stream_) == AAUDIO_OK;
    }

    void stop() {
        if (stream_) {
            AAudioStream_requestStop(stream_);
            AAudioStream_close(stream_);
            stream_ = nullptr;
        }
    }

    void sendCommand(const EngineCommand& cmd) {
        commandQueue_.push(cmd);
    }

private:
    static aaudio_data_callback_result_t dataCallback(
        AAudioStream* stream, void* userData, void* audioData, int32_t numFrames) {
        auto* engine = static_cast<AudioEngine*>(userData);
        return engine->render(static_cast<float*>(audioData), numFrames);
    }

    aaudio_data_callback_result_t render(float* output, int32_t numFrames) {
        // 1. Process lock-free UI commands
        EngineCommand cmd;
        while (commandQueue_.pop(cmd)) {
            // Apply note triggers / parameter updates without blocking
        }

        // 2. Clear master buffer
        std::fill_n(output, numFrames * 2, 0.0f);

        // 3. Render all active tracks into buffer
        for (auto& track : tracks_) {
            track->render(output, numFrames);
        }

        return AAUDIO_CALLBACK_RESULT_CONTINUE;
    }

    AAudioStream* stream_ = nullptr;
    LockFreeQueue<EngineCommand, 1024> commandQueue_;
    std::vector<std::unique_ptr<Track>> tracks_;
};
```

# 5. Non-Gradle Build System (`build.sh`)

This script compiles native C++ using the Android NDK, packages resources via `aapt2`, compiles Java/Dex via `d8`, and outputs a signed Android 14 APK.

### Complete `build.sh` Script
```bash
#!/usr/bin/env bash
set -e

# =================CONFIGURATION=================
export ANDROID_SDK_ROOT="/path/to/android-sdk"
export ANDROID_NDK_ROOT="/path/to/android-ndk"

API_LEVEL=34
BUILD_TOOLS_VERSION="34.0.0"
TARGET_ABI="arm64-v8a"
TARGET_TRIPLE="aarch64-linux-android"

PACKAGE_NAME="com.maxica.cobass"
PROJECT_DIR=$(pwd)
BUILD_DIR="${PROJECT_DIR}/build"
# ===============================================

TOOLCHAIN="${ANDROID_NDK_ROOT}/toolchains/llvm/prebuilt/linux-x86_64"
CC="${TOOLCHAIN}/bin/${TARGET_TRIPLE}${API_LEVEL}-clang"
CXX="${TOOLCHAIN}/bin/${TARGET_TRIPLE}${API_LEVEL}-clang++"
AAPT2="${ANDROID_SDK_ROOT}/build-tools/${BUILD_TOOLS_VERSION}/aapt2"
D8="${ANDROID_SDK_ROOT}/build-tools/${BUILD_TOOLS_VERSION}/d8"
ZIPALIGN="${ANDROID_SDK_ROOT}/build-tools/${BUILD_TOOLS_VERSION}/zipalign"
APKSIGNER="${ANDROID_SDK_ROOT}/build-tools/${BUILD_TOOLS_VERSION}/apksigner"
PLATFORM_JAR="${ANDROID_SDK_ROOT}/platforms/android-${API_LEVEL}/android.jar"

# 1. Clean & Setup Build Tree
rm -rf "${BUILD_DIR}"
mkdir -p "${BUILD_DIR}/obj" "${BUILD_DIR}/lib/${TARGET_ABI}" "${BUILD_DIR}/gen" "${BUILD_DIR}/dex"

echo "==> [1/6] Compiling C++ Audio Engine..."
${CXX} -O3 -std=c++20 -shared -fPIC \
    -DANDROID -D__ANDROID_API__=${API_LEVEL} \
    -I"${PROJECT_DIR}/jni" \
    "${PROJECT_DIR}/jni/main.cpp" \
    -laaudio -llog -landroid -lm \
    -o "${BUILD_DIR}/lib/${TARGET_ABI}/libcobass.so"

echo "==> [2/6] Compiling Resources with AAPT2..."
mkdir -p "${BUILD_DIR}/compiled_res"
${AAPT2} compile --dir "${PROJECT_DIR}/res" -o "${BUILD_DIR}/compiled_res/"

${AAPT2} link "${BUILD_DIR}/compiled_res"/* \
    -I "${PLATFORM_JAR}" \
    --manifest "${PROJECT_DIR}/AndroidManifest.xml" \
    --java "${BUILD_DIR}/gen" \
    -o "${BUILD_DIR}/app.unaligned.apk" --auto-add-overlay

echo "==> [3/6] Compiling Java Sources..."
javac -d "${BUILD_DIR}/obj" \
    -cp "${PLATFORM_JAR}" \
    "${PROJECT_DIR}/src/java/com/maxica/cobass/MainActivity.java" \
    $(find "${BUILD_DIR}/gen" -name "*.java")

echo "==> [4/6] Converting to DEX with D8..."
${D8} --min-api ${API_LEVEL} \
    --lib "${PLATFORM_JAR}" \
    --output "${BUILD_DIR}/dex" \
    $(find "${BUILD_DIR}/obj" -name "*.class")

# Merge DEX and Native SO into APK package
cd "${BUILD_DIR}"
"${ANDROID_SDK_ROOT}/build-tools/${BUILD_TOOLS_VERSION}/aapt" add -k "app.unaligned.apk" "dex/classes.dex"
mv "dex/classes.dex" "${BUILD_DIR}/"
zip -uj "${BUILD_DIR}/app.unaligned.apk" "${BUILD_DIR}/classes.dex"

# Add Native Libraries to APK structure
mkdir -p "${BUILD_DIR}/apk_root/lib/${TARGET_ABI}"
cp "${BUILD_DIR}/lib/${TARGET_ABI}/libcobass.so" "${BUILD_DIR}/apk_root/lib/${TARGET_ABI}/"
cd "${BUILD_DIR}/apk_root"
zip -ur "${BUILD_DIR}/app.unaligned.apk" "lib"
cd "${PROJECT_DIR}"

echo "==> [5/6] Aligning APK with ZipAlign..."
${ZIPALIGN} -f -v 4 "${BUILD_DIR}/app.unaligned.apk" "${BUILD_DIR}/Cobass.aligned.apk"

echo "==> [6/6] Signing APK..."
# Generate temporary debug key if not existing
if [ ! -f "${BUILD_DIR}/debug.keystore" ]; then
    keytool -genkey -v -keystore "${BUILD_DIR}/debug.keystore" \
        -storepass android -alias androiddebugkey -keypass android \
        -keyalg RSA -keysize 2048 -validity 10000 \
        -dname "CN=Cobass, OU=Maxica, O=Maxica, L=World, S=World, C=US"
fi

${APKSIGNER} sign --ks "${BUILD_DIR}/debug.keystore" \
    --ks-pass pass:android \
    --key-pass pass:android \
    --ks-key-alias androiddebugkey \
    --out "${BUILD_DIR}/Cobass-release.apk" \
    "${BUILD_DIR}/Cobass.aligned.apk"

echo "=========================================================="
echo " BUILD SUCCESSFUL: ${BUILD_DIR}/Cobass-release.apk"
echo "=========================================================="
```
